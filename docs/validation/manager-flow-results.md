## 单元与存档回归

批量预检不改变当前状态；单元逐条校验后一起提交。测试覆盖合计人力、注意力、水量、现金不足；多个重复单元和经理/班组巡查别名；独立任务与决策链；相同请求重试不会重复创建。场景完整方案从原分配器预检，报价与正式提交费用相同。

112 次巡查的完整经营历史在模拟 5 MiB 写入配额内保存，恢复后的玩家视图及全部历史保持一致。旧 `observation-pool-v1` 编码可读取，下一次保存转为完整对象池；循环/损坏节点被拒绝。

单位验证包含中文立方米、公顷、毫米，英文 m³，以及 `/`、数字比例和单元 ID 不被错误翻译。信息新鲜度在表格显示“水分信息更新／作物与设备信息更新”，并说明是有效信息的更新时间，不是作物生长天数。0 天显示当天，实际天数不压成 5天+，没有有效观察显示暂无信息；另验收同次巡查后水分、作物/设备信息日期一致；次日传感器刷新水分信息时，作物/设备信息可以仍为一天前，此规则经用户确认。
